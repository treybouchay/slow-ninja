# Slow Ninja

Playful studio site for [Slow Ninja](https://slow.ninja/)—skill-based games since 2014, designed in a Sophun-Games-inspired fun layout with Slow Ninja colors.

## Run

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Stack

Next.js · TypeScript · Tailwind · shadcn/ui

## Pages

- `/` — Deliberately Fun one-pager (hero, games, studio, journal)
- `/games` · `/studio` · `/journal` · `/journal/[slug]`
